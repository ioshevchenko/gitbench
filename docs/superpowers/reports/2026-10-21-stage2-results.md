# Этап 2: итоги (ветка stage2-log-branches)

## Сделано
- Задачи 1–11 плана: перенос графа IntelliJ (217 его тестов проходят), виды Git Log и Branches, операции над коммитами и ветками.
- Финальное ревью (отдельный ревьюер) и часть исправлений:
  - зависание UI на больших историях (детали запрашиваются пачкой, строка считается один раз);
  - checkout remote-ветки при существующей локальной — как в IntelliJ (fast-forward или выбор Rebase/Drop);
  - `--` в фильтре лога (ветка с именем папки);
  - задержка 150 мс и кеш «In N branches» при выборе коммита;
  - `log.showSignature=false`, сообщение вместо пустого лога при неожиданной ошибке;
  - цвет текста выделения без фокуса;
  - одна операция на репозиторий одновременно (scheduling rule).
- Тесты: 385, все зелёные. Jar лежит в dropins CubeIDE.

## Доделано после перерыва
- Branches: перезагрузка дерева больше не применяет фильтр к Git Log заново.
- Удаление нескольких веток идёт одним заданием, по очереди, с остановкой на первой ошибке.
- Merge, rebase, «Checkout and Rebase» и Compare передают git полное имя ref (`refs/heads/...`), тег с тем же именем не мешает.
- Checkout remote-ветки, у локальной копии которой есть свои коммиты: диалог «Checkout and Rebase / Drop Local Commits / Cancel», как в IntelliJ.
