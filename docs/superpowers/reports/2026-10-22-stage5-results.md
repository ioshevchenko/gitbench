# Этап 5: итоги (ветка stage5-annotate)

## Сделано
- **Маркеры изменений.** Колонка «Gitbench Changes» на поле текстовых редакторов (C, ассемблер, обычный текст) справа от номеров строк. Изменения считаются относительно HEAD тем же сравнением IntelliJ, что и diff.
  - Цвета New UI: добавлено `7FC784`, изменено `88ADF7`, удалено `767A8A` (тёмная тема `549159`, `375FAD`, `868A91`).
  - Маркер шириной 4 px со скруглёнными концами. Удаление — короткая полоса на границе строк. При наведении маркер шире на 3 px, курсор — рука.
  - Маркеры обновляются через 200 мс после паузы в наборе, после операций Gitbench и при активации редактора (коммит из консоли).
  - Неотслеживаемый файл и файл вне репозитория — без маркеров. Добавленный файл — все строки зелёные.
- **Popup маркера** по клику: Previous Change, Next Change, Rollback Lines, Show Diff for Lines, Copy, как в IntelliJ. Ниже текст блока из HEAD, изменённые слова подсвечены как в diff.
  - Rollback Lines — одна правка документа, Ctrl+Z в редакторе её отменяет.
  - Show Diff for Lines открывает diff файла и ставит курсор на этот блок, в том числе в уже открытой вкладке.
- **Команды** Next Change, Previous Change, Rollback Lines (категория Gitbench) без клавиш. Привязать: Preferences → General → Keys.
- **Annotate with Git Blame** в контекстном меню поля текстового редактора, C и ассемблера. Колонка слева от номеров строк: дата («Today», «Yesterday» или `dd.MM.yyyy`) и автор, фон по возрасту коммита (21 цвет палитры IntelliJ), строки последнего коммита темнее.
  - Подсказка: hash, автор, дата и время, summary.
  - Клик — коммит в Git Log: открытый вид Git, иначе открытый Git Log, иначе открывается вид Git. Лог дождётся загрузки, если он ещё грузится.
  - Своё меню по правой кнопке: Show Diff, Copy Revision Number, Select in Git Log, Close Annotations. Повторный пункт Annotate with Git Blame тоже закрывает колонку.
  - Blame идёт по тексту редактора (`git blame --contents -`), поэтому несохранённые строки пустые. После паузы в наборе 500 мс blame повторяется.
- Тесты до ревью: 590, все зелёные (unit и uiTest).
  - Модели: изменения строк и rollback, база из HEAD (CRLF, кодировка windows-1251, неотслеживаемый и добавленный файл), разбор blame, blame с несохранённым текстом и в windows-1251, палитра, даты.
  - UI: пиксели маркеров и annotate, наведение и попадание мышью, трекер с быстрым вводом, popup (порядок кнопок, текст HEAD, rollback, навигация, Copy, Esc).
  - Не покрыто: колонки в настоящем редакторе Eclipse, меню поля, свёрнутые блоки (folding), Show Diff for Lines, клик в Git Log. Это работает только в запущенной IDE.

## Финальное ревью
Отдельный ревьюер нашёл 7 важных проблем; все исправлены, на каждую есть тест, который сначала падал:
- диапазоны маркеров и строки blame сдвигаются сразу при правке, как DocumentTracker IntelliJ, поэтому Rollback Lines сразу после правки не трогает чужие строки;
- колонки следуют за сменой входа редактора (переиспользуемый редактор поиска, Save As, переименование);
- проверки git для колонок не пишут в консоль Gitbench, репозиторий файла ищется один раз;
- закрытие annotate во время blame больше не роняет фоновый поток;
- проверка файла для Annotate with Git Blame идёт не в UI-потоке;
- правка документа не из UI-потока не ломает маркеры и annotate.

Тесты после исправлений: 653, все зелёные.

## Отступления от IntelliJ
- Next/Previous Change в popup прокручивают редактор, но popup остаётся на месте. IntelliJ открывает popup заново у нового блока.
- Пункт Annotate with Git Blame без галочки: состояние команды Eclipse общее, а колонка у каждого редактора своя.
- IntelliJ после правок пересчитывает номера строк annotate. Gitbench вместо этого повторяет blame по тексту редактора; результат тот же — новые строки пустые.
- Клик по строке annotate в IntelliJ ничего не делает, коммит открывается из меню. Здесь клик выбирает коммит в Git Log, как записано в спеке.
- Нет настроек annotate (показ ревизии, цвет по автору) и подсветки слов в popup по переключателю — подсветка слов включена всегда.

## Quick Diff в Eclipse
Eclipse рисует свой Quick Diff в колонке номеров строк, а с EGit сравнивает с git. Он не мешает Gitbench, но показывает изменения второй раз. Отключить: Preferences → General → Editors → Text Editors → Quick Diff → снять «Enable quick diff».
